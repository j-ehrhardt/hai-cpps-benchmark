Welcome to the Documentation of HAI-CPPS v2

The Hamburg AI Benchmark for Cyber-Physical Production Systems (HAI-CPPS) is a benchmark for evaluating AI methods in anomaly detection, diagnosis, reconfiguration, and planning for modular cyber-physical process plants.

HAI-CPPS comprises ten process-plant topologies with increasing complexity. A campaign run is either normal or contains exactly one enabled fault proxy in one module, enabling controlled and reproducible comparisons across plant and fault complexity.

HAI-CPPS includes:

  • OpenModelica simulation models

  • Published benchmark datasets

  • Validated generation, export, and release checks

  • Docker integration for reproducible execution

The v2 release separates online measurement features from simulator-derived oracle states and offline metadata. You can also create and simulate your own system constellations using the OpenModelica models and the HAI-CPPS command-line workflow.

Note

HAI-CPPS extends the Benchmark for Diagnosis, Reconfiguration, and Planning (BeRfiPl). You can access the previous version here: BeRfiPl Benchmark
