Installation

When using HAI-CPPS, you can download the published benchmark or run the simulations locally. For local execution, install the required simulator and Python environment. Alternatively, the supplied Dockerfile provides a reproducible simulation environment.

Requirements

For local installation:

Note:
Local usage has been tested on Ubuntu 22.04 LTS and Ubuntu 24.04 LTS. While the models run in the OpenModelica Shell and OpenModelica Editor, the supported generation workflow is the v2 command-line interface described below.

  • You need an installation of OpenModelica 1.25 and the OpenModelica Standard Library 4.0.0 to run the benchmark.

  • All additional Python requirements are listed in the venv.yml file in the benchmark’s GitHub repository.

Using Docker:

  • To run the simulation inside a container, you need a current version of Docker. Docker Compose is not required.

Installation

For local installation:

  1. Install OpenModelica by following the instructions on the OpenModelica website.

  2. Install the additional requirements:

    • We recommend a recent version of Miniforge.

    • Navigate to the repository root.

    • Create and activate the environment:

    mamba env create --file venv.yml
conda activate hai-cps

  3. Validate the supplied configuration before starting a simulation:

    python code/sim.py validate --config code/benchmark_setup.json

Using Docker:

  1. Navigate to the repository root and build the image:

    docker build --tag hai-cpps:v2 .

  2. The image validates the bundled configuration by default:

    docker run --rm hai-cpps:v2

  3. Mount a host location when running a simulation so that generated releases and Modelica build artifacts persist:

    mkdir -p output
docker run --rm -v "$PWD/output:/work" hai-cpps:v2 run \
  --config code/benchmark_setup.json \
  --campaign normal \
  --scenario ds1 \
  --output /work/results \
  --build-root /work/build \
  --seed 20260831
